To develop the basic structure of a Student Attendance App using Flutter and Dart.

Description:
Flutter is used to create the user interface of the Student Attendance App, while Dart is used for programming the application logic. The project starts from the main() function, which is the entry point of the application. The runApp() function loads the main Flutter widget and displays the application on the screen. The project uses MaterialApp as the root widget and provides the application theme and initial screen.

In this Student Attendance App, Dart classes are used to represent student information such as student name, roll number, course, attendance status, classes attended, and total classes. Flutter's widget-based architecture allows the application interface to be constructed using reusable widgets.

The basic application structure contains the main application file, screens, models, and reusable widgets. The Student class acts as the data model, while different Flutter widgets display the information.

Used in the project:

main()
runApp()
